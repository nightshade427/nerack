# Bundled modules

- `htmx.h`: `{{> htmx}}`; sets `is_htmx` on htmx requests.
- `datastar.h`: `{{> datastar}}` and `datastar()`; sets `is_datastar`, and the signals of its requests arrive as `input:` for `validate()`.
- `tailwind.h`, `daisyui.h`: `{{> tailwind}}`, `{{> daisyui}}` in `<head>`; classes in templates compile automatically.
- `cookie_auth.h`: cookie sign-in for HTTP. Mounts `login`, `logout`, `signup`, `account` (`/login` ...) with their pages (`account` uses `cookie_link()`, which writes a one-time, 10-minute code to `link_code` for linking a Reticulum identity); link with `{{url:cookie_auth:login}}`, log out with a POST form to `{{url:cookie_auth:logout}}`. `cookie_logged_in()` gates: sets `user_id`, else redirects to login and back. `cookie_session()` sets `user_id` and `user` (`id`, `email`, `short_name`) when signed in, and never fails (use it alone on public pages). Apps never query the users; ownership is the app's SQL: `and user_id = {{user_id}}` with `.error_on_empty = true`. Restyle a page with `overrides/cookie_auth/login.html` (or `signup`, `account`), or replace a resource by declaring it there under the same name, calling its action (`cookie_login()` ...).
- `rns_auth.h`: the same users over Reticulum; a peer's identity is bound to a user like a passkey. Mounts `login`, `signup`, `link` with Micron pages. `rns_logged_in()` gates (sets `user_id`, else shows the login page and returns afterwards); `rns_session()` loads `user` and never fails. No logout.
- One user across protocols: `user_id` is the same in `http()` and `rns()` pipelines. `auth_user()` finds or creates the user for a verified `email` (never a form value), naming a new one from `short_name` in context, and sets `user_id`; `cookie_sign_in()`/`rns_sign_in()` then sign them in and end the pipeline. SSO is an override of `cookie_auth`'s `login` redirecting to the provider, plus a module whose callback calls `auth_user()` then `cookie_sign_in()`.
- The auth modules publish `user_created`, `user_credentials_changed`, and `user_deleted` with `user_id`; subscribe to `user_deleted` to delete the app's own rows.
